# Discord-Bot-w-Minecraft-Sever-Integration
The ultimate discord to Minecraft server integration bot.

# Note
If you are searching for a simple click and add, automatically running discord bot, this is not
the place, a version like this is planned for release eventually, but for now, all of this code has to be run manually on
whatever device you are hosting your server on. This also only works for servers that YOU are hosting, third party hosting services
will not be able to communucate with the bot.

# Setup

## Creating the bot profile

- First, navigate to the Discord Developer Portal, and create a developer account.
- Create a new application, customise it to your liking, and take note of the bot token.
- Invite the bot to your server, the only permissions it requries are the creation of new roles, deletion of roles,
  sending messaqges, and deleting messaqges.
- On the device you are running the bot on (same one you are running your server on) download this repository.
- Install the latest version of python.
- Run "pip install discord" in command prompt.
- Open the installed files, locate the config file.
- Change the RCON password to the RCON password in your server.properties file.
  *If this is blank or a default password, change it to a secure one.
- Customize the bot to your liking
